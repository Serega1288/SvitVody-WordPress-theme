# Інструкції для Codex

Цей файл є головним змістом інструкцій для проєкту `www-svitvody`.

Перед виконанням задач у цьому проєкті потрібно читати відповідні файли з папки `.codex/instructions/`.

## Обов'язкові інструкції

- `.codex/instructions/01-html-to-wordpress.md` - перша частина: інтеграція HTML-верстки у WordPress, Docker, старі файли, assets, `header.php`, `footer.php`, `index.php`.
- `.codex/instructions/02-header.php.md` - друга частина: окрема робота з `header.php`.
- `.codex/instructions/03-footer.php.md` - третя частина: окрема робота з `footer.php`.
- `.codex/instructions/04-page-constructor.md` - четверта частина: конструктор секцій через ACF Flexible Content, шаблони блоків і джерела контенту.

## Загальне правило

- Якщо користувач просить тільки записати або оновити інструкції, не виконувати саму задачу.
